# Social Share Master

A WordPress plugin to add floating and inline social share buttons with Open Graph / Twitter meta support and a click-to-copy link feature.

## Features

- Floating sidebar and inline post-content share buttons.
- Networks: Facebook, Twitter/X, LinkedIn, WhatsApp, Pinterest, Email, Copy Link.
- Open Graph and Twitter Card meta tags.
- Per post-type control.
- Rounded, square and minimal button styles.
- Left or right floating position.

## Installation

1. Download `social-share-master.zip` from [Releases](https://github.com/mrshahbazdev/social-share-master/releases).
2. Upload and extract to `wp-content/plugins/social-share-master/`.
3. Activate the plugin.
4. Go to **Tools > Social Share Master** to configure networks and post types.
